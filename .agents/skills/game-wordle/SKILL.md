# PvP Wordle

AGENTS.md is the overview and the `framework` skill covers matches, secrets, pushes and the harness; the `ui` skill covers `GameFrame`, sheets and landscape. One async mode, `wordle:classic` (2 to 8, `minPlayers` 2 so the host taps Start). Nothing in it may favour whoever opens the app first: everyone plays the same word at once, every pick is sealed, and the shop resolves only when the last player is done.

## Settings

In `convex/wordle/modes.ts`, read by `rulesOf` in `convex/wordle.ts`: `goal` Words to win (3, 5, 7; default 5), `wordTime` Time per word (no limit, 12h, 1 day, 2 days; default 1 day), `shop` (on/off). A game has at most `roundsFor(goal)` = goal + 3 words. Endings: `words` (someone reached the goal), `rounds` (the words ran out), `resign` / `last_player`.

## File map

- `convex/wordle.ts`: `guess` (`{ id, word, row }`, `row` = the rows the phone saw, a stale one is refused), `pick` (`{ id, round, item | null, target? }`, changeable until the shop closes), `typing` (`{ id, letters }`, a draft count others see as dots), `board` (my view), internal `deadline` and `remind`, `wordleHooks`, and `guessAs` / `pickAs` / `rulesOf` / `REMIND_MS` for tests. Never rename these.
- `convex/wordle/engine.ts`: pure rules. `score`, `isGuessable`, `newGame`, `guess`, `choose`, `cantGuess`, `cantPick`, `waitingOn`, `roundDone`, `lastWord`, `buyOrder`, `finishRound`, `leave`, `standings`, `fogged`, `jammed`, `keyColors`, `ITEMS`.
- `convex/wordle/words.ts` (`GUESSES`, every 5-letter ENABLE word, concatenated) and `convex/wordle/answers.ts` (`ANSWERS`, 2000 common ones, server only). Both generated by `python3 scripts/gen-wordle-words.py`: ENABLE (public domain) words, answers being those in SCOWL's common lists (size 35 and under) minus plurals, past tenses and a hand-kept list of rude words and names (`LEFT_OUT`), ranked by Peter Norvig's web word counts (`count_1w.txt`). Only ENABLE words are shipped. No comments allowed in them, so the sources live here.
- `convex/wordle/text.ts`: `buyLine` (log and push lines), `roundPush`.
- `convex/wordle/preview.ts`: the link preview. Only public numbers, plus the last closed word's colors (the word itself once the game's over).
- `src/games/wordle/`: `WordleGame.tsx` (screen, `usePlay`, `useLive`, done panel, incoming banner, players strip, log and player sheets), `Board.tsx` (the grid: measured tile size, flips, shake, hop on a solve, the fog overlay), `Keyboard.tsx`, `ShopSheet.tsx`, `parts.tsx` (`ItemIcon`, `Coins`, `MiniBoard`, mark colours), `art.tsx`, `rules.ts`, `summary.ts`.
- `og/games/wordle.mjs` (colours under `WORDLE` in `og/palette.mjs`).

## Rules and invariants

- A round is one word, the same for everyone (`secrets` with no user holds `{ words }`, one per possible round). Each player gets `max` rows (6, minus Short fuse, plus Extra row, kept within 3..8).
- Pay when your word ends: `BASE_PAY` + 1 per position you turned green + (if solved) `SOLVE_PAY` + rows left. Start with `START_COINS`. `guesses` adds rows used, or `ROWS + 1` for a miss.
- The round waits on every live player to finish their word and then pick (an item or pass). No shop on the last word (`lastWord`: the final round, or someone done has reached the goal), so then it waits on words only. `waitingOn` drives `matches.waitingOn`.
- Closing (`finishRound`): anyone not done is closed as a miss (the deadline passes `force`); buys go in `buyOrder` (fewest coins, then fewest solved, then seat), each taking stock (`ceil(alive / 4)` per item, `SHOP_SIZE` of the 8 items offered per round) if they can still afford it; a miss costs nothing. Shields are counted first, then each attack in buy order: a shielded target bounces the first one. Pickpocket takes `STEAL` at once; everything else becomes an `Effect` on the target's next word. Jam picks 2 letters from `earotlisnc`, locked for the first `JAM_TURNS` guesses (the server refuses them). Fog hides rows 0..2 once you've guessed past them (the `board` query drops their letters and colours). Blackout leaves the keyboard uncoloured. Hint writes one letter of the next word into that player's secret.
- The closed word goes into `state.history` with everyone's guesses, marks and buys, so letters become public only once a word closes. While it's open, a player's guesses live only in their secret (`Mine`), and others' colours come back from `board` only once you're done with the word yourself.
- Winning: after a close, anyone on the goal ends it; standings by solved, then fewer guesses, then more coins; equal on all three share a place. Leaving makes you `out` (done and picked), last in standings; under two left ends it.

## Framework: `waitingOn`

`matches.waitingOn` (optional) lists everyone a simultaneous game waits on, alongside `turn`. `awaits(match, userId)` in `convex/lib/seats.ts` is what `badgeCount`, `attention` and `inbox` use, and `TurnChip` shows "Your move" or "Waiting on N". Wordle leaves `turn` unset, so the shared 8-hour `remind` never fires for it: `wordle:remind` pushes everyone still owed every 6 hours twice, then every 12, until the deadline. `finish` clears `waitingOn`.

## Pushes

Start: "PvP Wordle is on". A close: each live player gets "Word N is up" with what hit them (or bounced off their shield) and their own sold-out pick, or their tally. When everyone but one is in (3+ players), that one gets "Everyone's waiting on you". Results are the shared ones.

## The screen

`GameFrame`, not fullscreen. Portrait: top line (Word N / "It was CRANE" at the end, first to N, coins, Log), the players strip (`data-seat`, `data-solved`, `data-rows`, `data-done`; row dots, typing dots, effects on them), the board (`role=grid` "Your board", `data-rows`, `data-played`; `data-fog` on the fog overlay), then the dock at a fixed 184px: the keyboard (`role=group` "Keyboard", keys `data-key`, `data-mark`, `data-jammed`; each key's 44px hit area is an `::after` behind every key, in an `isolate` row) or the done panel (`data-my-word` won/lost, coins earned, everyone's colours as `MiniBoard`s `[data-board-of] [data-marks]`, the Shop button naming your pick, who it's waiting on). Landscape: top line, players and the keyboard (or done panel) on the left, the board as `aside`. The incoming banner (`data-incoming`) drops over the board at the start of a word you were hit in. Physical keyboards work too. Sounds: pick/recall typing, flip per tile, bingo on a solve, sweep on a miss, invalid on a refused word, tick/knock/ghost when others guess or finish, turn on a new word, slam when hit, chips on buying, win/lose.

## Driving it in tests

- Unit: `engine.test.ts` builds tables with `newGame` and a fixed rng and sets `stock` to all items; `server.test.ts` goes through `matches.queue`/`startGame` and uses `testing:wordleWord` for the answer.
- `testing:wordleWord({ id })` (current answer), `wordleGuessAs({ id, userId, word })`, `wordlePickAs({ id, userId, item, target? })`, `wordlePatch({ id, players })` (merge per-seat fields, e.g. coins).
- e2e (`e2e/wordle.spec.ts`): `openLobby(page, "wordle", "classic", settings)` and `fillLobby`; type through the Keyboard group; poll `getMatch` for `rows`, `picked`, `round`. `SCREENS=1 npm run test:e2e -- wordle` writes `e2e/.state/screens/wordle-*.png`.

## Gotchas

- `WordleState`, `Player`, `Mine`, `Buy` and `Round` are stored: never rename their fields; new ones optional.
- The answer lists are indexed by position (5 letters each); regenerating them changes nothing for running games, whose words are already in their secret.
- `typing` writes a draft at most once per change in letter count; drafts are cleared when a guess lands and when a word closes.

## Tests
